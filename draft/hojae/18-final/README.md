# 18번 화장실 기능 최종 발표안 (1장)

최종 발표에서는 20개 기능 중 8개 안팎만 보여 준다 (교수님). 화장실 기능은 **18-1 화장실 동반 입장 1장**으로 "한 칸 화장실에 방광 게이지 우선으로 조를 짜서 들여보낸다"는 의미가 보이게 정리했다.

| 기능 | 시작 | 보여 주는 것 | 메시지 |
|---|---|---|---|
| [req](req-18-1.md) · [seq](seq-18-1.md) 화장실 동반 입장 | 학생이 '소변 입장'을 누름 | 비어 있으면 바로 입장, 방광 게이지 계산, 공통 객체(테이블) 재사용, 설비 수만큼 동반 입장 조 편성, 동기 응답 뒤 처리 | 16 |

- 화장실 입장 및 퇴실(원래 18-2)은 발표 범위에서 뺐다. 발표 때는 "화장실이 비면 대기 조가 입장하고, 퇴실하면 다음 조가 들어간다"를 한 줄로 말한다 (#41 연결은 끊어져도 정합성은 있게).
- 화장실이 비어 있으면 대기로 등록하지 않고 바로 입장한다 (대기 등록 전에 먼저 확인).
