# 2-1. 참가비 계산 (초안)

> 발표용 규칙(presentation/RULES.md)과 11/23 교수님 피드백(FEEDBACK #31~41)을 반영한 초안이다. 형식은 설혜원 님 초안(draft/hyewon/10)을 따랐다. 원본 `requirements/req-02-1.md`(양수현)는 고치지 않았다.

## 명세

**Function:** 참가비 계산

**Description:** 학생이 모임 공지에서 '신청하기'를 누르면 신청 마감과 중복 신청을 확인하고, 학번으로 학년을 계산해 학년 가중치를 적용한 참가비를 학생에게 보여 준다.

**Input:** 학생 ID, 모임 ID

**Source:** 학생(모임신청UI), DB(모임·신청·회원 기록)

**Output:** 학년, 학생별 참가비, 신청 불가 안내

**Destination:** 모임신청UI

**Action:**

1. 학생이 모임신청UI의 모임 공지에서 '신청하기'를 누르면 시스템은 DB에서 모임 시작 시각을 조회한다. 모임 시작 시각 전날 오후 6시를 신청 마감 시각으로 하고, 현재 시각이 마감 시각과 같거나 지났으면 '신청 마감' 안내를 돌려주고 종료한다.
2. 시스템은 DB에서 같은 학생 ID와 모임 ID의 유효한 신청이 있는지 조회한다. 있으면 '이미 신청함' 안내를 돌려주고 종료한다.
3. 시스템은 DB에서 학생의 학번을 조회해 학년을 계산한다.
    - 학년 = 현재 연도 − 학번 앞 네 자리(입학 연도) + 1
    - 학번이 없거나, 앞 네 자리가 연도가 아니거나, 학년이 1보다 작으면 '참가비 계산 불가' 안내를 돌려주고 종료한다.
4. 시스템은 학년 가중치를 정한다. 1~2학년은 1.0, 3학년은 1.1, 4학년 이상은 1.2다.
5. 시스템은 DB에서 모임의 기본 참가비를 조회한다. 없거나 0원 이하이면 '참가비 계산 불가' 안내를 돌려주고 종료한다.
6. 시스템은 참가비를 계산해 '○학년 기준 참가비 ○○원입니다'를 모임신청UI에 돌려준다.
    - 참가비 = 기본 참가비 × 학년 가중치

**Requirements:**

- 신청 마감 시각은 모임 시작 시각의 전날 오후 6시다.
- '신청하기'는 모임 상태가 '모집중'인 모임 공지에만 표시된다.
- 모집 정원을 넘어도 신청 마감 전까지 신청할 수 있다.
- 한 학생은 같은 모임에 유효한 신청을 한 번만 할 수 있다.
- 복학·휴학 등은 반영하지 않고 학번의 입학 연도만으로 학년을 계산한다.

**Pre-condition:** DB에 학생의 동국대 이메일 인증 완료 상태와 학번이 저장되어 있고, 계정 상태가 '정상'이다. DB의 모임 상태가 '모집중'이다. DB 조회는 성공한다고 가정한다.

**Post-condition:** 조건을 모두 만족하면 모임신청UI에 학년 가중치를 적용한 참가비가 표시된다. DB에는 신청 기록이 생기지 않는다. 조건을 만족하지 못하면 신청 불가 안내가 표시된다.

**Side effects:** 없음 (DB를 조회만 한다).
