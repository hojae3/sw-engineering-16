# 클래스: QR출석

| 항목 | 내용 |
|---|---|
| 파일 | classes/QRAttendance.md |
| 종류 | 담당 객체 (기능 5) |
| 상태 | 추가 |
| 설명 | 학생 간 상호 QR 스캔 또는 사장님 확인 스캔을 통해 출석을 기록하고 테이블 출석 인원에 따라 주문 가능 상태를 갱신한다 |

## 속성

| 가시성 | 이름 | 타입 | 설명 |
|---|---|---|---|
| - | 모임ID | int | 대상 모임 식별자 |
| - | 학생ID | int | 출석 학생 식별자 |
| - | 테이블번호 | int | 배정된 테이블 번호 |

## 연산

| 가시성 | 시그니처 | 사용처 |
|---|---|---|
| + | 상호QR스캔요청(학생1ID: int, 학생2QR토큰: String, 모임ID: int) | seq-05 #1 |
| + | 사장님확인스캔요청(사장님ID: int, 학생QR토큰: String, 모임ID: int) | seq-05 #6 |
| - | QR토큰검증(QR토큰: String): boolean | seq-05 #2, #7 |
