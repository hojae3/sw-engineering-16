# 클래스: 친해지고싶은학생알림

| 항목 | 내용 |
|---|---|
| 파일 | classes/CloseStudentNotification.md |
| 종류 | 담당 객체 (기능 3) |
| 상태 | 추가 |
| 설명 | 신청DB에 신청 상태 '결제완료'가 저장되면 해당 학생을 관심 대상으로 등록한 학생들에게 확률적으로 모임 신청 알림을 발송한다 |

## 속성

| 가시성 | 이름 | 타입 | 설명 |
|---|---|---|---|
| - | 모임ID | int | 처리 중인 모임 |
| - | 대상학생ID | int | 결제를 완료한 관심 대상 학생 |
| - | 관심등록학생목록 | List<int> | 대상 학생을 등록한 학생 ID 목록 |
| - | 알림확률 | double | 1 ÷ 등록한 학생 수 |
| - | 발송대상목록 | List<int> | 확률 판정에 선정된 발송 대상 학생 목록 |

## 연산

| 가시성 | 시그니처 | 사용처 |
|---|---|---|
| + | 결제완료저장됨(학생ID: int, 모임ID: int) | seq-03 #1 (Found Message) |
| - | 알림확률계산(등록인원: int): double | seq-03 #4 |
| - | 발송대상선정(학생ID목록: List<int>, 확률: double): List<int> | seq-03 #5 |
| + | 알림선택(학생ID: int, 모임ID: int) | seq-03 #7 |
