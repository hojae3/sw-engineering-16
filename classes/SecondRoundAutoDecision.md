# 클래스: 2차참가자동결정

| 항목 | 내용 |
|---|---|
| 파일 | classes/SecondRoundAutoDecision.md |
| 종류 | 담당 객체 (기능 20) |
| 상태 | 추가 |
| 설명 | 2차 공지가 등록되면 출석 학생의 응답을 모으고 '고민' 학생의 참가 여부를 결정한다 |

## 속성

| 가시성 | 이름 | 타입 | 설명 |
|---|---|---|---|
| - | 모임ID | int | 처리 중인 모임 |
| - | 응답목록 | List<참가응답> | 10분 동안 받은 마지막 응답 |
| - | 이번참가비율 | double | '참가' 학생 수 ÷ 알림을 받은 학생 수 |
| - | 결과목록 | List<참가결과> | 학생별 결정 결과 |

## 연산

| 가시성 | 시그니처 | 사용처 |
|---|---|---|
| + | 2차공지등록됨(모임ID: int) | seq-20 #1 (Found Message) |
| + | 참가응답제출(학생ID: int, 선택: 참가선택) | seq-20 #6 |
| - | 응답별결정(응답목록: List<참가응답>) | seq-20 #7 |
| - | 참가비율계산(참가수: int, 알림수: int): double | seq-20 #8 |
| - | 불참결정(학생ID: int) | seq-20 #13, #14 |
| - | 참가여부결정(과거2차참가율: double, 이번참가비율: double): 2차참가결과 | seq-20 #16 |
