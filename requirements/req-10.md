# 10. 만난 사람 평가

## 명세

**Function:** 만난 사람 평가

**Description:** 모임 종료 후 '만난 사람 평가' 화면을 학생UI에 표시해 같은 테이블 출석 학생의 매너를 평가하게 한다. 평가를 모아 매너 점수를 다시 계산한다. 갱신된 매너 점수는 프로필DB에 저장된다.

**Input:** 평가하는 학생 ID, 모임 ID, 평가받는 학생 ID 목록, 학생별 평가 점수 목록

**Source:** 학생UI, 모임DB, 출석DB, 배치DB, 프로필DB, 평가DB

**Output:** 평가 제출, 갱신된 매너 점수, 평가 제출 완료 안내

**Destination:** 평가DB, 프로필DB, 학생UI

**Action:**

1. 모임DB의 모임 상태가 '종료'로 바뀌면 시스템은 출석DB에서 그 모임에 출석한 학생을 조회한다. 학생마다 배치DB와 출석DB에서 본인을 제외한 같은 테이블 출석 학생 목록을 조회하고, 프로필DB에서 해당 학생들의 프로필 사진을 가져와 '만난 사람 평가' 화면을 학생UI에 표시한다.
2. 평가하는 학생은 같은 테이블 출석 학생의 프로필 사진을 확인하고, 각 학생에게 매너 점수(1~5점)를 입력한다.
3. '평가 완료'를 누르면 입력한 점수를 한 번에 평가DB에 저장한다.
4. 시스템은 배치DB와 출석DB에서 제출한 학생 본인을 포함한 같은 테이블 출석 학생을 조회하고, 평가DB에서 그 학생 전원이 평가를 제출했는지 확인한다.
5. 전원이 제출했으면 제출한 학생 본인을 포함해 평가받는 학생마다 평가DB에서 받은 점수 목록을, 프로필DB에서 기존 매너 점수와 평가한 학생들의 매너 점수를 조회해 매너 점수를 다시 계산하고 프로필DB에 저장한다. 평가한 학생들의 매너 점수는 이번 계산으로 갱신되기 전의 값을 쓴다. 같은 테이블에 아직 평가를 제출하지 않은 학생이 있으면 매너 점수는 다시 계산하지 않고, 마지막 학생이 제출할 때 계산한다.
    - 새 매너 점수 = (기존 매너 점수 + 받은 점수의 합 + 매너 점수 4점 이상인 평가하는 학생이 준 점수 한 번 더) ÷ (1 + 평가하는 학생 수 + 매너 점수 4점 이상인 평가하는 학생 수)
6. 평가 제출 완료를 학생UI에 알리고 처리를 종료한다.

**Requirements:** 익명으로 처리하고, 평가받는 학생에게 누가 몇 점을 주었는지 공개하지 않는다. 평가 대상은 본인을 제외한 같은 테이블 출석 학생으로 한정한다.

**Pre-condition:** 모임DB의 모임 상태가 '종료'이다.

**Post-condition:** 평가DB에 평가가 저장되고 대상 학생의 최신 매너 점수가 프로필DB에 기록된다.

**Side effects:** 평가DB에 평가 기록이 추가되어 저장 데이터가 증가하며, 학생의 매너 점수가 프로필DB에 갱신된다. 모임 종료 직후 다수의 학생이 동시에 평가를 제출할 때 일시적으로 요청이 집중될 수 있다.
