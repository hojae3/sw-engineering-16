# 10. 만난 사람 평가

> 출처: PPT 15쪽. 원문을 템플릿에 옮기고 표기(공백 제거, enum 값, 대표 용어)만 맞췄다. CONVENTIONS 4장 규칙에 맞게 다듬는 것은 담당자가 한다.

## 명세

**Function:** 만난 사람 평가

**Description:** 모임 종료 후 '만난 사람 평가' 화면을 학생UI에 표시해 같은 테이블 출석 학생의 매너를 평가하게 한다. 평가를 모아 매너 점수를 다시 계산하고, 그 점수를 다음 모임의 자리 배치 생성 시 매너 점수 반영에 쓴다.

**Input:** 평가하는 학생 ID, 모임 ID, 평가받는 학생 ID 목록, 학생별 평가 점수 목록

**Source:** 학생UI, 출석DB, 배치DB, 프로필DB, 평가DB

**Output:** 평가 제출, 갱신된 매너 점수, 평가 제출 완료 안내

**Destination:** 평가DB, 프로필DB, 학생UI

**Action:**

1. 모임DB의 모임 상태가 '종료'로 바뀌면 시스템은 참가한 학생UI에 '만난 사람 평가' 화면을 표시한다. 시스템은 배치DB에서 같은 테이블 학생을 조회하고, 출석DB에서 출석한 학생만 평가 대상으로 정한 뒤, 프로필DB에서 프로필 사진을 가져와 표시한다.
2. 평가하는 학생은 같은 테이블 출석 학생의 프로필 사진을 확인하고, 각 학생에게 매너 점수(1~5점)를 입력한다.
3. '평가 완료'를 누르면 입력한 점수를 한 번에 평가DB에 저장한다.
4. 시스템은 같은 테이블 출석 학생 전원이 평가를 제출했는지 확인한다.
5. 전원이 제출했으면 평가받는 학생마다 평가DB에서 받은 점수 목록을, 프로필DB에서 기존 매너 점수와 평가한 학생들의 매너 점수를 조회해 매너 점수를 다시 계산하고 프로필DB에 저장한다.
    - 새 매너 점수 = (기존 매너 점수 + 받은 점수의 합 + 매너 점수 4점 이상인 평가하는 학생이 준 점수 한 번 더) ÷ (1 + 평가하는 학생 수 + 매너 점수 4점 이상인 평가하는 학생 수)
6. 평가 제출 완료를 학생UI에 알리고 처리를 종료한다.

**Requirements:** (PPT에서 잘림, 확인 필요)

**Pre-condition:** (PPT에서 잘림, 확인 필요)

**Post-condition:** (PPT에서 잘림, 확인 필요)

**Side effects:** 평가DB에 평가 기록이 추가되어 저장 데이터가 증가하며, 학생의 매너 점수가 프로필DB에 갱신된다. 모임 종료 직후 다수의 학생이 동시에 평가를 제출할 때 일시적으로 요청이 집중될 수 있다.
