# 1. 모임공지등록

## 명세

**Function:** 모임공지등록

**Description:** 사장님이 모임 이름, 시작 시각, 모임 종료 시각, 모집 정원, 기본 참가비, 품앗이 참여 여부를 입력하면, 시스템이 입력값을 검증하여 학생이 신청할 수 있는 모임 공지를 등록한다.

**Input:** 사장님 ID, 가게 ID, 모임 이름, 시작 시각, 모임 종료 시각, 모집 정원, 기본 참가비, 품앗이 참여 여부, 요청 식별자

**Source:** 사장님UI, 가게DB

**Output:** 등록된 모임 공지, 등록 실패 안내

**Destination:** 모임DB, 사장님UI, 학생UI

**Action:**

1. 사장님이 사장님UI에서 '모임공지등록'을 선택하고 모임 이름, 시작 시각, 모임 종료 시각, 모집 정원, 기본 참가비, 품앗이 참여 여부를 입력한 후 등록을 요청한다.
2. 시스템은 가게DB에서 사장님 ID와 가게 ID가 일치하는 등록된 가게가 있는지 확인한다. 일치하는 가게가 없으면 등록 실패를 사장님UI에 알리고 처리를 종료한다.
3. 시스템은 모집 정원이 12명 이상이면서 4의 배수인지 확인한다. 조건을 만족하지 않으면 등록 실패를 사장님UI에 알리고 처리를 종료한다.
4. 시스템은 기본 참가비가 0원보다 큰지 확인한다. 조건을 만족하지 않으면 등록 실패를 사장님UI에 알리고 처리를 종료한다.
5. 시스템은 모임 종료 시각이 시작 시각보다 늦은지 확인한다. 조건을 만족하지 않으면 등록 실패를 사장님UI에 알리고 처리를 종료한다.
6. 시스템은 시작 시각의 전날 오후 6시를 신청 마감 시각으로 계산하고, 신청 마감 시각이 현재 등록 시각보다 늦은지 확인한다. 조건을 만족하지 않으면 등록 실패를 사장님UI에 알리고 처리를 종료한다.
7. 시스템은 모임DB에서 동일한 요청 식별자로 등록된 모임이 있는지 확인한다. 이미 등록된 요청이면 기존 등록 결과를 사장님UI에 반환하고 새 모임을 저장하지 않는다.
8. 모든 검증에 성공하면 시스템은 모임 이름, 일정, 모집 정원, 기본 참가비, 품앗이 참여 여부, 요청 식별자를 모임DB에 저장하고 모임 상태를 '모집중'으로 설정한다.
9. 시스템은 등록된 모임 공지를 사장님UI에 반환하고 학생UI의 모임 공지 목록에 조회 가능하도록 한다.

**Requirements:**

- 동일한 요청 식별자로 등록 요청이 반복되어도 모임DB에 중복 저장하지 않는다.
- 모임 상태가 '모집마감'이 된 이후에는 모집 정원, 기본 참가비, 모임 종료 시각을 수정할 수 없다.
- 신청 마감 시각은 모임 시작 시각의 전날 오후 6시로 설정한다.

**Pre-condition:** 가게DB에 사장님 ID와 연결된 가게 ID가 등록되어 있다.

**Post-condition:** 모임DB에 모임 상태가 '모집중'인 모임 공지가 저장되며, 학생UI에서 조회할 수 있다. 등록 실패 시 모임DB에 새로운 모임 공지가 저장되지 않는다.

**Side effects:** 모임DB에 새로운 모임 공지 레코드가 추가되어 저장 데이터가 증가한다.
