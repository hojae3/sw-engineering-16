# 15. 당일 안심귀가

> 출처: PPT 20~21쪽. 원문을 템플릿에 옮기고 표기(공백 제거, enum 값, 대표 용어)만 맞췄다. 하버사인 공식 그림은 글로 옮겼다. CONVENTIONS 4장 규칙에 맞게 다듬는 것은 담당자가 한다.

## 명세

**Function:** 당일 안심귀가

**Description:** 모임 종료 뒤 학생의 현재 위치와 사전 등록한 자택 위치로 귀가 마감 시각을 계산하고, 도착이 확인되지 않으면 앱운영자에게 긴급 문자를 보낸다.

**Input:** 모임 ID, 학생 ID, 현재 위치 좌표(위도, 경도), 자택 위치 좌표(위도, 경도), 모임 종료 시각, 비상 연락처, 안전 확인 응답, 위치 권한 동의, 긴급 연락 동의

**Source:** 학생UI, 프로필DB, 모임DB, 단말기위치정보

**Output:** 귀가 마감 시각, 귀가 알림, 안전 확인 알림, 긴급 문자

**Destination:** 학생UI, 앱운영자

**Action:**

1. 모임 종료 시각이 되면, 시스템은 단말기위치정보로부터 학생의 현재 위치 좌표를 수신하고, 프로필DB에서 자택 위치 좌표를 조회한다.
2. 학생의 현재 위치 좌표와 프로필DB의 자택 위치 좌표를 기반으로, 지구 반경(R = 6371km)을 적용한 하버사인 공식을 통해 두 지점 간의 대원 거리(d)를 계산한다.
    - 현재 위치를 위도 φ1·경도 λ1, 자택 위치를 위도 φ2·경도 λ2라 하고, Δφ = φ2 − φ1, Δλ = λ2 − λ1이다.
    - a = sin²(Δφ ÷ 2) + cos(φ1) × cos(φ2) × sin²(Δλ ÷ 2)
    - d = 2R × arcsin(√a)
3. 산출된 직선거리 d에 도심 도로 굴곡 계수 1.3을 곱하여 추정 도로 이동 거리 D(km) = d × 1.3을 설정한다.
4. D에 따라 이동 수단 및 이동 시간을 산출한다.
    - D가 1.5km 이하이면, 도보 이동으로 판정. 추정 이동 시간(분) = (D ÷ 4km/h) × 60.
    - D가 1.5km 초과이면, 차량 이동으로 판정. 추정 이동 시간(분) = (D ÷ 25km/h) × 60.
5. 귀가 마감 시각 = 모임 종료 시각 + 추정 이동 시간 + 30분(여유 버퍼)으로 계산하여 학생UI에 알리고 위치 추적 모니터링을 시작한다.
6. 모니터링 중 자택 반경 100m 이내 진입이 감지되면 학생UI에 '안전하게 귀가하셨습니다' 알림을 표시하고 위치 확인을 정상 종료한다.
7. 귀가 마감 시각까지 자택 반경 100m 내에 진입하지 못한 경우, 시스템은 즉시 학생UI에 '안전 확인 알림'을 발송하고 10분 타이머를 시작한다.
    - 10분 내 학생이 안전 응답을 누르면, 모니터링을 종료한다.
    - 10분 내 응답이 없으면, 시스템은 프로필DB를 조회하여 즉시 앱운영자에게 학생 기본 정보(이름, 학번), 비상 연락처를 포함한 비상 긴급 문자를 자동 발송하고 프로세스를 마감한다.

**Requirements:** 학생의 위치 권한·긴급 연락 동의가 있어야 실행한다. 이동 경로는 저장하지 않는다.

**Pre-condition:** '9. 자동 정산'에서 모임이 종료되었다. 모임 종료 시각은 '1. 모임공지등록'에서 입력한다. 학생은 자택 위치·비상 연락처를 등록하고 위치 권한에 동의해 두었다.

**Post-condition:** 귀가·안전 응답 확인 시 모니터링을 종료하며, 확인하지 못하면 앱운영자에게 긴급 문자를 보낸다.

**Side effects:** 귀가 학생마다 단말기 위치 추적 및 귀가 예상 시간에 따른 타이머가 동작하며, 예상 시간 초과 및 미응답 시 비상 연락처로 긴급 문자(SMS) 외부 서비스 호출이 발생한다. 모임 종료 시각에 다수 학생의 귀가 추적 처리가 한꺼번에 몰릴 수 있다.

## 정리할 것

- Action 2~4의 이동 시간 계산은 공통 객체 귀가시간계산의 `이동시간추정`과 같다 (20번과 공유, classes/ReturnHomeTimeCalc.md). 시퀀스에서는 그 연산을 재사용한다.
